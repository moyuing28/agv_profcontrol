## 数据约定

- 导出 API.Stations 全部站点；距离表 N×N，保留方向，A→B 与 B→A 分别计算，对角线为 0。
- API 异常、不可达、负距离、无效 CurrentIdx、double.MaxValue、Infinity 统一输出 NaN，统计 DistanceFailureCount。
- stations.csv 每个站点/巷道关系一行；交汇站点可重复出现；不属于巷道的站点一行且巷道字段为空。StationCount 是唯一站点数而非 CSV 行数。
- X/Y 直接读取 IStation.View.KeyPoint，为系统坐标。读取失败留空并 Warning。
- PocketKey 沿用项目巷道首站 Mark 的标识约定；首站冲突时增加 #2/#3 后缀并 Warning，保证本次导出唯一，不修改原项目的键。
- PocketName 读取地图两位数字分类，并沿用 MapConfig 的完整单物理巷道校验规则。为了保留无参静态入口、避免跨实例绑定，模块不直接读取 SampleProject 私有 cargoPocketKeysByName/stationPocketKeys 缓存；复用其原始分类和 BelongPocketLines/OrderStations 关系。多名称映射留空并 Warning。
- IsCargoSlot 表示“车库位”分类内且不在“入口”分类的货位，不表示当前有货。IsPocketEntrance 和 lanes.csv 的 Entrance 仅依据“入口”子分类，不再使用 pocket.Gate。
- UTF-8 无 BOM，CSV 逗号/引号/换行按标准转义，数字使用 InvariantCulture。
- 最外层异常保护，日志自身也受保护；失败不向业务抛异常。若磁盘写入途中失败，四个文件可能未全部更新，以日志 Finished、metadata ExportTime/ExportStatus 为准，不把失败后的旧文件作为新实验数据。
